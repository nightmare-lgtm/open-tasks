В приложении два сценария получения данных: Прямое и использованием композебл

Прямое - мы просто получили данные, и отобразили/отрисовали их.
Для случаев Простого запроса - минуем композеблс. Вызывается асинхронный composable Nuxt, в который прокидываются функции из сервиса

С использованием композебл-сценарий, который требует еще дополнительной логики обработки на клиенте. Это фильтрация, объедение нескольких данных из разных запросов и тд. Для этого уже выступает композеблс. Для каждой страницы они будут свои, и со страницы в асихронный composable Nuxt прокидывается наш.
